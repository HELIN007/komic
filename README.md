## 📖 项目简介

**Komic** 是一款以「统一多源内容入口 + 极简沉浸式多媒体体验」为核心构建的现代 Android 应用。  
打破传统单一格式阅读器的壁垒，Komic 深度整合了漫画、电子书、有声书的全流程消费场景，构建了从远程多源接入、离线缓存管理、Bangumi 漫画与书籍资源发现到 AI 硬件加速画质超分的一体化阅读与视听体验。

### 🌟 核心特性一览

- 🌐 **全方位多源聚合**：原生接入 `Komga`、`Kavita`、`Audiobookshelf`、`WebDAV` 网盘与本地文件存储。
- 📚 **全品类多媒体体验**：
  - **漫画阅读**：条漫（Webtoon）、日漫（右向左）、左向右模式，双页拼页/拆分，智能白边裁切，真实纸张质感，自动滚动。
  - **电子书阅读**：基于 Foliate-js 内核，支持 EPUB、PDF、TXT 流式排版，内置思源与霞鹜字体，支持分栏、目录、书签及精细版面调节。
  - **有声书播放**：深度集成 Audiobookshelf，支持后台锁屏播放、通知栏媒体控制、无感浮动 MiniPlayer、倍速播放、睡眠定时器与离线下载收听。
- 🧭 **Bangumi 书籍探索 & 双向书库互绑**：接入 Bangumi 丰富的漫画与书籍条目元数据，支持热门榜单探索、标签分类检索；业内首创**资源与服务器书库双向互绑**机制，一键映射并秒开本地/服务器对应馆藏。
- ⚡ **AI 画质硬件加速**：基于 NCNN C++ 原生引擎，支持 GPU 硬件加速超分辨率推理（内置 `waifu2x-anime`、`waifu2x-cunet`、`real-cugan`）。
- 🎨 **Material 3 灵动体验**：全面支持 Edge-to-Edge 边到边沉浸式视界，支持 Dynamic Color 动态取色、AMOLED 纯黑模式、细腻震动反馈、主界面 Tab 自由排序与显隐定制。
- 🛡️ **安全与数据生态**：支持隐藏书库 PIN 密码锁、多层级分类缓存清理仪表盘、阅读统计、端到端数据完整备份与跨机恢复。

## 🗂️ 核心架构与模块

Komic 提供 7 大核心主入口，支持在「设置 → 外观 → Tab 栏显隐与排序」中自由拖拽排序或按需隐藏：

```
Komic 主入口体系
├── 📁 书架 (Bookshelf)        # 多服务器媒体库统一浏览、层级下钻、PIN 锁隐藏库保护、多选批量管理
├── 📖 在读 (Keep Reading)     # 跨源阅读历史与进度流式同步、实时记忆、无缝断点续读
├── 🎧 听书 (Audiobook)        # Audiobookshelf 媒体库、系列/作者归纳、沉浸式播放器与浮动 MiniPlayer
├── 📦 离线库 (Offline)        # 离线漫画/电子书/已下载有声书统一归档、本地文件夹实时变更监听
├── 🖥️ 服务器 (Servers)       # Komga / Kavita / WebDAV / ABS 统一连接拓扑、状态监控与管理
├── 🧭 资源 (Discover)        # Bangumi 漫画与书籍探索、标签筛选、与 Komga/Kavita 双向书库匹配与互绑阅读
└── ⚙️ 设置 (Settings)        # 动态配色、Tab 定制、阅读参数、AI 引擎、存储与备份恢复
```

## 🚀 核心能力矩阵

### 1. 多源互联与双向生态
- **Komga**：无缝同步系列、书籍、单话、封面海报与跨端阅读进度。
- **Kavita**：深度适配系列层级与卷本结构，支持高速阅读管道与双向进度同步。
- **Audiobookshelf (ABS)**：支持有声书流式播放、作者/系列聚合、书签同步、多服务器快速切换与 Polo 协议服优化。
- **WebDAV 网盘**：远程目录树流式解析，支持大包 ZIP/CBZ 在线解析，支持常用路径书签化。
- **本地存储**：智能扫描内部与外部存储漫画路径，支持文件夹热变动监听。
- **Bangumi 资源映射**：在探索漫画与书籍资源时，自动匹配并直观展示「在我的书库」状态，实现作品探索与自有书库的无缝联动。

### 2. 差异化沉浸式阅读器

| 阅读能力 | 漫画阅读器 (`MangaReader`) | 电子书阅读器 (`EbookReader`) | 有声书播放器 (`AudioPlayer`) |
|---|---|---|---|
| **核心内核** | 原生多视图渲染引擎 | Foliate-js 高精度排版内核 | 原生 `audio_service` + `just_audio` |
| **支持格式** | ZIP, CBZ, RAR, CBR, PDF, 图片目录 | EPUB, PDF, TXT, 结构化电子书 | MP3, M4A, M4B, FLAC, AAC 等 |
| **交互控制** | 9 宫格点击热区自定义、自动滚动速度调节 | 仿真翻页/连续滚动、分栏阅读 | 浮动 MiniPlayer、后台通知栏、锁屏控件 |
| **排版增强** | 智能裁切白边、双页拼页/拆分、纸张质感纹理 | 字号/行距/段距微调、多款内置字体 | 0.5x ~ 3.0x 倍速、睡眠定时器、章节跳转 |
| **特殊功能** | AI 画质超分辨率（GPU 加速） | 多级目录树导航、书签卡片标注 | 离线整本/分章节下载、断点续听 |

### 3. 本地 AI 画质增强引擎
- 基于 NCNN 原生 C++ 库，充分释放 `arm64-v8a` 设备性能，支持 Vulkan GPU 硬件加速。
- 内置针对动漫插画与漫画线稿深度优化的主力模型：
  - **`waifu2x-anime`**：经典动漫图像超分辨率与降噪。
  - **`waifu2x-cunet`**：高质量纹理保留与高保真线条放大。
  - **`real-cugan`**：新一代高动态插值超分，针对模糊与压缩失真图块进行智能复原。

### 4. 存储、缓存与数据安全
- **全方位缓存控制**：独立隔离管理 AI 超分缓存、Bangumi 图片/响应缓存、切边缓存与音频流缓存，支持精细化一键释放。
- **端到端备份恢复**：支持书架分类、服务器配置、阅读进度、个性化设置的多类别选择性导出与导入。
- **安全私密**：支持对特定敏感媒体库设置独立 PIN 码保护，切换后台或离开应用时自动锁定。

## 📱 系统要求与安装

### 系统环境
- **处理器架构**：**`arm64-v8a`**（专为 64 位 ARM 处理器深度调优）
- **最低兼容系统**：**Android 8.0+**（API 26+）
- **推荐运行环境**：**Android 14.0+**（API 34 ~ API 37），以获得最佳 Edge-to-Edge 边到边全面屏视效与 Material 3 动态色彩联动。
- **硬件建议**：如需使用 AI 画质超分辨率功能，建议使用配备 4GB 及以上 RAM 且支持 Vulkan 的设备。

### 安装步骤

1. 前往项目的 [Releases](../../releases) 页面，下载最新的安装包。
2. 在设备上点击打开安装包。若系统提示「禁止安装未知来源应用」，请前往 **系统设置 → 应用安全** 授予安装权限。
3. 安装完成后启动应用，输入激活码完成设备授权即可开启完整体验。

## 🚀 快速上手

### 1. 设备激活
首次打开应用进入激活界面，输入您的激活码完成激活；您还可以选择填入联系方式，以便日后更换设备时一键找回或迁移。

### 2. 接入数据源
- **Komga / Kavita 服务器**：  
  前往「设置 → 服务器管理 → 添加服务器」，选择服务器类型，填入服务器地址与账户凭据，测试通过后保存。
- **Audiobookshelf 有声书服**：  
  前往「设置 → 服务器管理 → 添加服务器」，类型选择 Audiobookshelf，配置连接后即可在「听书」Tab 中即时畅听。
- **WebDAV 网盘**：  
  前往「设置 → 服务器管理 → 添加 WebDAV 服务器」，配置连接后可在书架中挂载，并将常用目录加入书签。
- **本地漫画与书籍**：  
  前往「设置 → 存储设置 → 本地路径」，授权访问本地存储并添加漫画/有声书根目录，应用将自动建立索引。

### 3. 开启阅读与听书
- 在「资源」Tab 探索最新热门漫画与书籍榜单，在条目详情页通过「在我的书库」一键直达服务器藏卷。
- 在「书架」中自由浏览各大服务器的分库与系列，点击进入极速流式阅读。
- 在「在读」Tab 随时查看全源最新进度并一键无缝续读。

## 📋 支持格式规范

| 类别 | 支持文件扩展名 | 适用数据源 | 支持特性 |
|---|---|---|---|
| **漫画图像包** | `.cbz`, `.zip`, `.cbr`, `.rar` | 全部（本地 / WebDAV / 服务器） | 实时流式解压、双页拆分、白边裁切、AI 增强（WebDAV支持部分流式解压） |

| **本地图片目录** | 包含 JPG / PNG / WEBP 的文件夹 | 本地离线库 | 目录树扫描、文件热变动实时监听与自动刷新 |

## ❓ 常见问题

<details>
<summary><b>Q: 安装时提示「解析软件包时出现问题」怎么办？</b></summary>

本项目专为现代化 64 位芯片深度构建，仅分发 `arm64-v8a` 架构安装包。请确保您的设备或模拟器不是 32 位系统（armeabi-v7a 或 x86），且 Android 系统版本 ≥ 8.0。
</details>

<details>
<summary><b>Q: AI 画质超分辨率使用时设备发热或耗时较长？</b></summary>

AI 增强算法采用本地 NCNN 神经网络引擎直接在设备端离线推理计算，属于计算密集型任务。应用已默认启用 GPU 硬件加速并采用单核切片调度。建议在设备电量充足以获得更佳的实时渲染速度。
</details>

<details>
<summary><b>Q: 资源页与书库双向互绑是如何工作的？</b></summary>

当您在「资源」Tab 浏览或检索 Bangumi 漫画/书籍条目详情时，系统会自动与您当前已连接的 Komga / Kavita 服务器书库进行匹配计算，并在详情页顶部展示该作品在您书库中的关联藏本。确认绑定后，您可以在资源详情页直接点击阅读按钮无缝开始阅读，服务器系列详情页也会双向同步展示该条目元数据。
</details>

<details>
<summary><b>Q: 更换手机或重装系统后，激活码如何找回？</b></summary>

如果您在首次激活时填写了联系方式（手机号/邮箱），可直接在激活界面的「设备号」Tab 下通过绑定的信息一键激活；若未绑定或遇到迁移问题，可联系作者进行处理。
</details>
